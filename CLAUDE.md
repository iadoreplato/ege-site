# Проект: учебник-конструктор ЕГЭ по английскому (сайт)

Автор и владелец проекта — Дарья, учитель английского. Она не программист: объясняй простыми словами, что меняешь и зачем, и перед крупными изменениями показывай план.

## Команды
- `npm install` — установить зависимости (один раз)
- `npm run dev` — запустить сайт локально (http://localhost:5173)
- `npm run build` — проверка типов + сборка в `dist/`. Запускай после каждого изменения кода, чтобы убедиться, что ничего не сломалось.

## Устройство
- `src/content/*.json` — ВЕСЬ учебный контент (единственный источник; из этих же файлов собирается PDF-версия).
  - `universal.json` — универсальный блок; `frames.t4`, `frames.t37`, `frames.t38` — шаблоны ответов, общие для всех модулей.
  - `sport.json`, `russia.json` — тематические модули. Новый модуль = новый JSON той же структуры + импорт в `src/App.tsx` (массив `topics`).
- `src/components/` — React-компоненты, рисуют контент по полю `type` у блока.
- `src/styles.css` — оформление; палитра в `:root` (кремовый, тёмно-синий, терракота).
- `public/img/` — иллюстрации Fluent Emoji (MIT); в JSON имя без `.svg`.
- `netlify/functions/check.mjs` — серверная функция проверки открытых заданий через ИИ.

## Разметка внутри текстов JSON
- `[[слово]]` — выделенный ключевой элемент (предлог, частица, коллокат)
- `(U)` — неисчисляемое существительное
- `sb`, `sth`, `+ -ing` — грамматические пометы
- `___` — пропуск в шаблонах и упражнениях; `{a|b|c}` — варианты выбора в предложении

## Правила контента (обязательны при любых правках модулей)
- Уровень B2–B2+; форматы упражнений по образцу Cambridge (English Vocabulary in Use, B2 First).
- Всё на английском, кроме переводов слов, русских предложений для перевода и официальных русских инструкций к заданиям 11 и 19–36 из демоверсии.
- Формулировки заданий 1–4, 37, 38 — дословно как в демоверсии ЕГЭ 2027.
- В каждом упражнении 10–15 пунктов. Позиция правильного ответа в вариантах ДОЛЖНА меняться, без повторяющегося рисунка.
- Лексика: глаголы с `to`, неисчисляемые помечены `(U)`, к каждой фразе пример употребления, ключевые элементы выделены `[[ ]]`.
- В каждом юните есть задание 2. Модуль заканчивается блоком повторения: задание 11, 19–24, 25–29, 30–36, перефраз, перевод.
- Задание 38: аудитория опроса одна во всём тексте; респонденты chose / opted for, не mentioned.
- Только оригинальный контент или официальные материалы ФИПИ — никакого текста из платных сборников.

## Чего не делать без явной просьбы
- Не менять структуру JSON (названия полей): от неё зависят и сайт, и PDF.
- Не удалять файлы и не переписывать компоненты целиком ради мелкой правки.
- Не добавлять сбор персональных данных учеников (аккаунты, сохранение записей на сервер).

## Аудирование: уровень и сложность
- Текст записи немного сложнее задания; уровень не ниже B2. В модуле чередуются юниты B2–B2+ и B2+–C1 (поле level).
- Утверждения и варианты перефразируют текст (без совпадения 4 слов подряд). Неверные варианты в записи упоминаются, но с другим смыслом.
- Task 2: Not stated = связанная деталь, о которой не сказано; False = противоречие.
- Task 3: варианты одной длины и типа; правильный не самый длинный; вопросы в порядке текста.

## Разделы юнита, нумерация, чтение и обсуждение
- Вкладки юнита: Vocabulary, Practice, Listening, Reading, Use of English, Writing, Speaking. Вкладки «Exam tasks» нет. Названия, диапазоны заданий ЕГЭ, подписи типов и русские формулировки берутся из `src/content/sections.json`, не из кода компонентов.
- Задания в каждом разделе юнита нумеруются подряд (Task 1, 2, 3…). Заголовок карточки: «Unit 3 · Reading · Task 2» и метка номера ЕГЭ. Номер считается кодом, в JSON не хранится.
- Чтение: `src/content/reading/*.json`. Формат 10: 7 текстов по 55–80 слов (целиться в 60–75) и 8 заголовков из 2–4 слов (один лишний); 11: 6 пропусков и 7 частей (одна лишняя); 12–18: текст 600–650 слов и 7 вопросов по 4 варианта; среди вопросов обязательно есть «NOT mentioned», значение выражения (mean) и отсылка местоимения (refer). Темы близкие подросткам, часто личная история или бытовой сюжет, не энциклопедическая статья. Те же правила сложности, что для аудирования: уровень не ниже B2, варианты перефразируют текст, неверные варианты правдоподобны.
- После проверки в заданиях аудирования и чтения показывается блок Discuss (поле `discuss`, не менее 3 вопросов) и расшифровка записи.

## Тренировочные варианты (Practice tests)
- Три полных варианта лежат в тех же папках контента с `module: "variant"` и `unit: 1..3`: `listening/variant-N-t1|t2|t3`, `reading/variant-N-t10|t11|t12`, `use-of-english/variant-N-t19|t25|t30`, `writing/variant-N`, `speaking/variant-N`. Проверка: `node scripts/make-audio.mjs --check`, `node scripts/check-reading.mjs`, `node scripts/check-variants.mjs`.
- Тема каждого задания в варианте бытовая и своя, темы не повторяются между разделами и вариантами. Лексика не привязана к модулям курса.
- Формат Use of English: `t19` и `t25`: `rows` [номер, текст до, текст после, слово-основа] и `key`; `t30`: `text` с метками `<b>30</b>`…`<b>36</b>`, `opts` [номер, 4 слова] и `key` (номера 1–4). В ответах `/` значит «любой из вариантов».
- Письмо: `writing/variant-N.tasks` = [email (задание 37), essay (задание 38)] в формате `speech` юнита. Устная часть: `speaking/variant-N.tasks` = [reading, ad, interview, photo] (задания 1–4), в ad добавлено поле `questions` (4 образцовых вопроса).
- Нумерация заданий ЕГЭ внутри варианта совпадает с демоверсией: 1–9, 10–18, 19–36, 37–38, устная часть 1–4.

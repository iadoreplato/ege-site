# Фотографии для заданий 2, 3 и 4 устной части

Чтобы заменить иконку на фото, положите сюда файл с нужным именем из списка ниже.
Подходят форматы .jpg, .jpeg, .png и .webp, имя должно совпадать точно (маленькие буквы, дефисы).
Если файла нет, на сайте остаётся иконка. В задании 3 без фото просто ничего не показывается.
Лучше всего горизонтальные фото шириной 1200–1600 пикселей.

Записи голоса, которые скачивают ученики, называются так же (например, sport-u1-task3.webm),
так что по имени файла видно, к какому заданию запись.
